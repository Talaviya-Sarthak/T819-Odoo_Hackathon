# Frontend

## Installation

```bash
npm install
npm run dev
```

## Environment

Edit `.env` and set:

- `VITE_API_URL` - Backend URL (default: http://localhost:5000)

## Development

The frontend runs on http://localhost:5173

## About

This is a minimal authentication reference implementation.
You can:

- Keep it as-is
- Customize the UI
- Replace with your own pages
- Connect to your existing application

The `/dashboard` route is a protected page that demonstrates the authentication flow.
